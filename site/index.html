Cài đặt

Bốn bước, chưa tới hai phút.

  1. Tải file ZIP

    Bấm nút Tải game ở đầu trang.

  2. Giải nén ra thư mục riêng

    Chuột phải → Extract All…, ví dụ D:\Games\VanDao. Không chạy trong ZIP, không đặt trong Program Files.

  3. Mở Launcher

    Chạy NguoiLuoiTuTienLauncher.exe. Launcher tự kiểm tra và tải bản mới.

  4. Bấm Chơi

    Dải game hiện trên taskbar. Chuột phải lên dải để đổi vị trí, kích thước, ngôn ngữ hoặc ẩn xuống khay.

Tiến độ lưu trong %LocalAppData%\VanDao — cập nhật bản mới không mất nhân vật.

Windows báo “đã bảo vệ PC của bạn”?

Game chưa có chữ ký số nên Windows SmartScreen cảnh báo ở lần chạy đầu. Bấm Thông tin thêm rồi Vẫn chạy. Nếu phần mềm diệt virus chặn, hãy chỉ tải game từ trang này.

Yêu cầu

  • Windows 10 hoặc 11, 64-bit · khoảng 500 MB trống
  • Microsoft Edge WebView2 Runtime (có sẵn trên Windows 11; Windows 10 tải tại đây)
  • Internet cho Thiên bảng, Chợ và cập nhật · đã kèm sẵn .NET
