Original library code: source/fire.ts and source/explosion.ts.
Custom demo: three independent effect silhouettes, formations and animation timelines.
Rebuild with Node 24+ and Python/Pillow:
python prepare.py
node render.mjs
python build.py
Intermediate RGBA files are regenerated by these scripts.
WebP may coalesce identical frames; PNG sheets retain all 90 frames.

V6 explosion-generated.png: newly generated with built-in ImageGen using user-provided visual reference. Reference is not copied into the runtime atlas. Sprite Fusion MIT notice above remains applicable to source library layers.
